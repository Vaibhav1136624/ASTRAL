ASTRAL — WINDOWS DESKTOP EDITION

Double-click Astral.exe to play. Keep the entire folder together.
Runs offline in a dedicated Microsoft Edge app window; Edge must be installed. No separate web server or Node installation is needed.

Includes 101 chambers, the crescent/prism logo, animated opening screen, Continue, level selection, sound toggle and fullscreen. Click ASTRAL in the game to return home. Close the window to quit.

Progress is stored in a separate local profile under %LOCALAPPDATA%\AstralGame\Profile. Existing browser-game saves are separate.
The launcher serves only on this computer at 127.0.0.1:18767 while the app runs.

Source: source/Astral.cs and the game, menu and assets files. The executable is locally compiled and unsigned.
